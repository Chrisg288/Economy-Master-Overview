# UI Review v0.3.4

## Datagrid acceptance checks

1. Every product/service record occupies one physical row.
2. No cell wraps to a second line.
3. Long text is truncated with an ellipsis and the full value appears on hover.
4. A horizontal scrollbar appears at the bottom of the datagrid.
5. The inspector opens as a fixed right-side flyout and does not change the center layout width.
6. Existing tree resizing and parent counts remain unchanged.

The asset URLs are versioned with `?v=0.3.4` to defeat stale GitHub Pages/browser caches.
