# Core Design Principles

## Human / Consumer Tree
The TreeView is the fastest route to identify what the user wants or needs. It is ordered from immediate survival to lower-priority comfort and lifestyle wants.

## Comparator Datagrid
After a need is selected, related options are shown in a sortable datagrid. Users choose visible columns and may click a header for primary sorting or Shift-click for secondary sorting.

## Separation of concerns
- Needs tree = human purpose and priority
- Product/source library = evidence and acquisition inputs
- Datagrid = decision surface
- User Profile = weighting lens
- Ribbon = context lens
