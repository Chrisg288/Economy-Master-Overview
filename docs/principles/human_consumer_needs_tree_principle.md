# Human / Consumer Needs Tree Principle

The Human / Consumer TreeView is not a random product catalog.

It is a priority-ordered list of what the user wants or needs, with survival needs first and low-priority wants last.

Product catalogs are mapped under or across these needs. A catalog category is not automatically a need. It is evidence/source material that may fulfill a need.

After a need is selected, the Comparator datagrid lets the user sort options by fulfillment, survival value, total cost, availability, durability, risk, evidence, and status.


## Current compiled source library

This package includes 66 source inventory records. These sources support the need tree but do not replace it.
