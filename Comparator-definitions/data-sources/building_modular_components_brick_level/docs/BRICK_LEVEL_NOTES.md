# Building Modular Components — Brick-Level Notes

This package treats windows, doors, garage doors, steel fire-rated doors, railings, HVAC, water heaters, duct sections, electrical/wiring components and lighting as modular building components.

These classes are ideal for Comparator because they have measurable fields: size, performance rating, material, configuration, code evidence, energy rating, listing/certification, installation constraints, price and availability.

The brick-level seed should be refined by ingesting catalogues and registry data from NRCan, NFRC, AHRI, DLC, CCMC, manufacturer PDFs, ARCAT/Sweets/BIMobject and retailer/distributor sources.
