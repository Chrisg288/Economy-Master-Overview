# Computer / IT / Communications Source Notes

Strong open/reference sources:
- NVD CPE dictionary for product/version identifiers.
- ENERGY STAR certified computers for verified efficiency/product records.
- EPEAT registry for sustainability-certified electronics.
- FCC Equipment Authorization and ISED REL for radio/RF/wireless certification evidence.
- FCC grantee registrations for downloadable manufacturer/grantee lookup.
- RadioReference for radio frequency/talkgroup context, where terms allow.

Communications categories include cell phones, Wi-Fi/Bluetooth/networking, CB/FRS/GMRS, amateur/shortwave radio, microwave/RF equipment, antennas, coax, satellite/GPS/marine communication and RF test equipment.

Live catalog sources such as Ingram Micro, TD SYNNEX, CDW and Dell require partner/reseller/customer credentials.
