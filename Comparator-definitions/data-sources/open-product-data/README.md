# Open Product Data Sources v0.1

This GitHub Pages-ready package catalogues **22** official/open product-data sources and includes two current source files:

- Government of Canada recall/safety-alert CSV: **33,672 rows**
- NHTSA vPIC all-makes CSV: **12,269 rows**

It also includes download scripts for USDA food data, selected ENERGY STAR datasets, NHTSA, CPSC and optional Health Canada/Open Food Facts acquisition.

## Design rule

These sources provide product records, specifications, certifications, ingredients and risk evidence. They should be linked to the unified meaningful Comparator tree and NAPCS classifications, not used as a replacement for human-facing classes.
