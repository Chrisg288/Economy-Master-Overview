# Tools / Fasteners / Hardware / Property / Cabinet Source Notes

This domain is especially valuable for Comparator because it contains measurable, comparable fields:
thread, grade, material, coating, size, capacity, extension, overlay, load rating, application, package quantity and price per unit.

High-value source groups:
- Industrial/MRO: Grainger, Fastenal, Gregg, Bolt Supply, MSC, Zoro, McMaster.
- Canadian/local: Canadian Tire, Gregg Distributors, Red Deer Bolt, Red Deer Fasteners, Bolt Supply Red Deer, Lee Valley.
- Cabinet/kitchen hardware: Richelieu, Blum, Accuride, Häfele, Hettich.
- Classification/procurement: UNSPSC, GS1 GPC, NAPCS.

Important distinction:
- A manufacturer catalog page is a specification/evidence record.
- A distributor/retailer product page is an offer/current availability record.
- A local supplier page is a local sourcing record.
- A standard classification is a taxonomy/crosswalk record.
