# Comparator Catalog Acquisition Run 01 — Open Sources

This package adds a runnable acquisition job for the first open/no-key sources.

It can acquire:
- Open Food Facts Canada product sample.
- NVD CPE product dictionary sample.
- ENERGY STAR Certified Computers.
- ENERGY STAR Certified Residential Refrigerators.
- NHTSA vPIC vehicle makes.
- Fastenal Fastener Reference Guide PDF.
- Accuride Drawer Slide Wood Catalog PDF.

It includes:
- Local Python downloader.
- Manual GitHub Actions workflow.
- Source target configuration.
- Account/API target checklist.
- PDF parse queue.
- Vendor-positive data rule.
