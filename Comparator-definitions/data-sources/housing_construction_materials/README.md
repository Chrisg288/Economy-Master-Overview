# Housing / Construction Materials Product Data Sources v0.1

This GitHub-ready package is a source catalogue and acquisition plan for populating the Comparator with housing, construction materials, hardware and home-improvement products.

There is no single free public download for all Home Depot, RONA, Home Hardware, Lowe's Canada and construction manufacturer products.

Best path:

official classification/evidence layer
+ retailer API/portal where available
+ manufacturer catalog/spec directories
+ paid scraping APIs only if needed
+ later server-side product database
