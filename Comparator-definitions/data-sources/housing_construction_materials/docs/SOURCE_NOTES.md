# Source Notes

Retailers:
- Lowe's has an official Product Catalog API portal for product, price, promotion and inventory access.
- Home Depot appears to rely on supplier systems and has no obvious public product catalog API. Third-party APIs exist.
- RONA publishes supplier product-content and dropship documentation, but not an obvious public product feed.
- Home Hardware has a large public catalogue and supplier guide, but no obvious public product API.

Better immediate official/reference sources:
- CCMC Registry: Canadian product/code assessment evidence.
- NRCan Searchable Product List and ENERGY STAR Canada: verified energy-efficiency products.
- ICC-ES and UL Product iQ: compliance/certification evidence.
- ARCAT, Sweets, BIMobject and BIM&CO: manufacturer catalog/spec/BIM sources.

Comparator interpretation:
- Retailer rows are live offers.
- CCMC/UL/ENERGY STAR/NRCan rows are evidence and assessment records.
- ARCAT/Sweets/BIM rows are product/specification reference records.
- NAPCS provides classification.
