# Housewares / Kitchenwares / Appliances / Clothing Source Notes

Best immediate product data sources:
- ENERGY STAR and NRCan for appliance certification and performance records.
- Best Buy API for appliance/electronics current and historical retail rows.
- GS1/GPC and GS1 Canada ECCnet for classification and product identity, with access requirements.
- Fashion Product Images, Fashionpedia, Atlas and iMaterialist for clothing taxonomy and attribute training.

Interpretation:
- Retail API rows are live offers.
- ENERGY STAR/NRCan rows are verified performance/evidence records.
- GS1/ECCnet rows are identity/product-content records.
- Fashion datasets are taxonomy/image/attribute evidence, not current retail offers.
