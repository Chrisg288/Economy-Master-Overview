# Furnishings / Furniture Source Notes

Best immediate sources:
- BIFMA LEVEL and BIFMA Compliant for furniture sustainability/safety/durability evidence.
- IKEA/Wayfair public catalogs and developer/third-party API paths for current retail furniture references.
- Skulytics for commercial product-data API access for furniture, mattresses and appliances.
- ARCAT, Sweets, BIMobject and BIM&CO for manufacturer/spec/BIM product references.
- GS1 GPC and NAPCS for classification.

Do not treat retail catalog rows, certification rows and BIM/spec rows as the same record type. Link them through product identity, category and manufacturer/model.
