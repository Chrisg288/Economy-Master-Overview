# Newark Catalog 112 (1992) - Comparator Conversion Pilot

This GitHub-ready package demonstrates conversion of a historical printed catalog into a Comparator-style TreeView, typed datagrid and inspector.

Included: 158 representative hand-validated records, CSV/JSON data, section tree, schema, status methodology and full-conversion plan.

The package separates **Catalog Record Status = Obsolete** from **Product Lifecycle Status = Unverified**.

Install by dragging the included `Comparator-definitions` folder into the repository root. The GitHub Pages viewer path will be:

`https://chrisg288.github.io/Economy-Master-Overview/Comparator-definitions/historical-catalogs/newark_catalog_112_1992/`

This is a pilot from clear pages, not the complete 1,248-page conversion.
