# Full Catalog Conversion Plan

This package is a representative conversion pilot, not the complete 1,248-page extraction.

1. Import the 16 catalog sections, Product Index and Manufacturers Index.
2. Detect recurring table templates by section/manufacturer.
3. Extract each row with source PDF page, printed page and confidence.
4. Visually review ambiguous rows.
5. Mark each 1992 catalog listing as an obsolete historical record.
6. Verify current part lifecycle using present manufacturer/distributor sources.
7. Link replacements, alternates, evidence and NAPCS codes.
8. Expose records through the Comparator TreeView, typed datagrid and transaction/evidence tools.
