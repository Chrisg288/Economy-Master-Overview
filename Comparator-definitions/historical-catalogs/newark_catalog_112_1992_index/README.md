# Newark Catalog 112 Index + Current Online Comparator Bridge v0.1

This package converts the first useful layer of the 1992 Newark Electronics Catalog 112 into Comparator-style data:

- top-level catalog section structure
- representative product-index rows
- representative manufacturer-index rows
- current Newark/electronics sourcing data-source catalogue
- current online category rows
- current sample offer rows
- a seed historical-to-current category crosswalk
- an interactive GitHub Pages viewer

Viewer path after upload:

https://chrisg288.github.io/Economy-Master-Overview/Comparator-definitions/historical-catalogs/newark_catalog_112_1992_index/

This is not a full catalog conversion yet. It is the index bridge and current-online acquisition layer.
