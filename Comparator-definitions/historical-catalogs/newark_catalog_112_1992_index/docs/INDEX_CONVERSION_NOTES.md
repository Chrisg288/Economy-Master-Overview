# Newark Catalog 112 Index Conversion Notes

This package converts the first useful index layer of Newark Catalog 112 into Comparator-style data.

The uploaded catalog explains that the Product Index is a comprehensive product listing on pages 1180-1195, and the Manufacturers Index lists suppliers and product pages on pages 1196-1200. These are the right first conversion targets before extracting full page product tables.
