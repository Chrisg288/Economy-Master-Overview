# Linked Product Records — 10,000

This dataset contains exactly 10,000 real processed product-linked records:

- 9,842 Government of Canada recall/product-safety records from the existing Open Product Data package.
- 158 structured Newark Electronics Catalog 112 (1992) product records.

These are not claimed to be 10,000 current retail offers. Recall records are safety/evidence records; Newark records are historical and obsolete. Every record is explicitly labelled by record type and status.

Each record links to the Human / Consumer tree through `need_id`, `fulfillment_id`, `category_group_id`, `page_id`, `product_node_id`, and `tree_path_ids`.
