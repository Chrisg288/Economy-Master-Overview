# ISED Financial Performance Data 2024 — Small Business Calibration v0.1

GitHub-ready calibration library built from the uploaded 24 official CSV files.

- 2024 NAICS descriptions: **2,059**
- Priority business types: **17**
- Parsed benchmark contexts: **204**
- Fully suppressed contexts: **6**
- Partially suppressed contexts: **41**

Install by merging the included `Business-Simulator` folder into the Economy-Master-Overview repository.

Values in revenue, expense-value and balance-sheet sections are thousands of Canadian dollars. Expense percentage files are percentages of total revenue.
