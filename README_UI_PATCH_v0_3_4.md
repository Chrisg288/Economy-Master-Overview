# Economy Master UI Patch v0.3.4

This patch specifically fixes the Comparator datagrid regression seen on GitHub Pages.

- forces exactly one physical line per record;
- uses fixed field widths and ellipsis;
- adds a real horizontal scrollbar inside the datagrid;
- preserves full values in hover tooltips;
- keeps the inspector as an overlay flyout;
- adds cache-busting query strings so GitHub Pages/Chrome cannot keep the old CSS and JavaScript.
